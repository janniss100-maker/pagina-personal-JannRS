# Página personal de criptografía

Página de **Tania Jannet Reyes Santamaria**, estudiante de ESCOM, IPN.

**Sitio en vivo:** [https://pagina-personal-jann.netlify.app/]

Incluye presentación y fotografía, formación académica, correo electrónico y redes sociales, tres imágenes de hobbies, una sección biográfica sobre Alan Turing, el CV en PDF y el enlace «Mi llave pública». La llave se agregará al realizar la práctica de RSA.

## Abrir localmente

Abre el archivo `index.html` en cualquier navegador, o ejecuta el comando `python3 -m http.server 8000` en tu terminal y visita `http://localhost:8000`.

## Actualizar la página

Edita el archivo `index.html`. Todos los recursos multimedia se incluyen en la carpeta `assets` y no requieren servicios externos. El sitio se publica y actualiza en automático desde la rama `main` mediante la integración con Netlify.
